Local mouse teleoperation simulation (no hardware)
-------------------------------------------------
PushT is installed via LeRobot's pusht extra. Start from this directory:
    .venv/bin/python teleop_pusht.py
Hold the left mouse button in the window to move the blue circular pusher.
Push the T-shaped block onto the green target. R resets; Esc quits.
This launcher uses LeRobot's PushtEnv, make_env, and preprocess_observation
with the local gym-pusht physics environment. It tests simulation and LeRobot
observation processing, not an SO101 hardware driver or a learned policy.

Automated check without opening a desktop window:
    .venv/bin/python teleop_pusht.py --check
Output: verification-pusht.log

SO101 physical teleoperation with both USB cameras
-------------------------------------------------
    .venv/bin/python teleop_so101_cameras.py
This command enables physical follower movement and opens Rerun camera views.
Stop any previous teleoperation process with Ctrl+C before running it.
Uses the calibrated IDs leader and follower, the previously identified USB
ports, and OpenCV camera indices 0 and 1 at 640x480, 30 fps. Both cameras were
tested simultaneously through LeRobot's OpenCVCamera and delivered frames.
Camera indices may change when devices are reconnected.

The launcher adapts Rerun's newer Scalars name to the older Scalar API in
Rerun 0.22.1; no installed package files are modified.
Hardware-free display logging check:
    .venv/bin/python teleop_so101_cameras.py --check
